# Drel 主屏幕添加流程 · 人性化审查简报

## 目标
判断“放到 iPhone 主屏幕”的 Safari 入口页三步流是否清晰、流畅、无歧义，找出任何会让用户卡住、误解或误操作的地方。

## 背景
- App：Drel 1.5.0 (98)。
- 长按“我的应用”里的应用磁贴 → 设置弹窗 → “添加到 iPhone 主屏幕…”。
- 引导：1 复制 HTTPS 入口链接；2 打开入口页 → Safari 分享 → 添加到主屏幕；3 从主屏幕点图标回到 Drel 并进入对应应用。
- iOS 不允许 App 静默创建主屏幕图标，必须由用户在 Safari 确认名称和图标。

## 审查问题
- 每一步的动作是否一眼能看懂？按钮和文案是否有歧义？
- “入口链接已复制”“打开入口页”“添加到主屏幕”是否容易混淆？
- 深色模式、半屏/全屏切换、关闭/返回路径是否清楚？
- 从 Safari 添加成功后回到 Drel 的预期是否交代清楚？
- 有没有更人性化的简化空间？请给出具体改法。

## 输出格式
- 总体结论：清晰 / 基本清晰但有改进点 / 有明显歧义。
- 问题清单：按严重程度排序，附具体截图和位置。
- 改进建议：可落地的文案或布局修改，最多 8 条。
