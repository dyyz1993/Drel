# Drel 1.4.1 What's New

The 1.4.1 line is a hotfix train for the 1.4 release. The 1.4.0 App Store
version is already `READY_FOR_SALE` and its locked `whatsNew` cannot be
replaced, so this document is the approved copy for the 1.4.1 record.

## zh-Hans

```text
Drel 1.4.1 更新

• 稳定性修复：修复若干收藏夹、收件箱与通知路由的显示问题
• 离线应用：应用资源按 SHA-256 校验后保存在本地，断网时也能启动
• 深层链接：drel://app 可打开已注册的可信应用指定路由
```

## en-US

```text
What's new in Drel 1.4.1

• Stability fixes: corrected several display issues in Favorites, the Inbox and notification routing
• Offline apps: app resources are verified with SHA-256 and stored locally so they launch without a network
• Deep links: drel://app opens a specific route in a registered trusted app
```

Keep the heading synchronized with the editable App Store version. Build
numbers alone do not prove that a version record has been created.
