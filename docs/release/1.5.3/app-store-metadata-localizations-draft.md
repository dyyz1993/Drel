## en-US（修订版）

说明：当前线上英文描述比中文版少「收藏常用页面」「浏览可信的签名应用」两条要点，本稿补齐对齐。

### description

Drel is a push notification tool and a secure container for trusted HTML apps on iPhone.

• Copy your personal push URL and send notifications from scripts, browsers, automations, or your own services.
• Open HTTPS pages directly from notifications.
• Review opened messages in your inbox and save frequently used pages as favorites.
• Browse signed, trusted apps and open them or add them to your home screen.
• With your consent, trusted apps can request controlled actions including haptics, sharing, fullscreen, clipboard, location, motion sensors, and real-time sound level.

Try Voice Jump and Dandelion: after granting microphone access, the live sound level controls web interactions. Manage permissions anytime in the permission center.

Web pages run only in the foreground with explicit user action. Controlled actions require a signed declaration; unauthorized requests are rejected. Drel is designed for developers using their own services — it is not a public app marketplace.

Built with WebBridgeKit.

## 主语言切换方案（P0，随 1.5.3 提交）

实测确认：未覆盖语言的 App Store 页面回退到**主语言（当前为 zh-Hans）**，不是英文（kr/br/ru 等 lookup 已验证显示中文）。切换主语言到 en-US 后，所有未覆盖地区将回退英文，zh-Hans 用户不受影响。

执行方式（已核实 API 无此字段，`appInfos` 属性不含 primaryLocale，只能网页操作）：

1. 1.5.3 版本提交前，在 ASC →「App 信息」→ 语言设置中，把主语言从「简体中文（主要）」改为「英语（美国）」。前置条件已满足：`en-US` 的 App 级本地化已存在（名称 Drel、副标题 Developer Push Notifications）。
2. 主语言变更随 1.5.3 版本审核一起生效，不需要单独审核。
3. 上线后用 `itunes lookup` 抽查 2-3 个未覆盖地区（如 jp、kr、br）确认回退语言已变为英文。

## 语言数量说明

App Store 支持的语言数量没有上限，可以随时新增本地化，不需要一次做完。两种语言（中英）是最小可用配置，但对全球开发者工具来说不够——未覆盖地区会显示主语言。合理的做法是：主语言英文兜底 + 按市场逐步增加 ja/ko/de 等本地化，每一轮随版本提交即可，已上架内容不受影响。
