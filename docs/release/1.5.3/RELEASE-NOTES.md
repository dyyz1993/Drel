# Drel 1.5.3 Release Notes

Draft for TestFlight.

## 简体中文

- 网页应用可以安全查询当前环境、能力声明及授权状态。
- 优化已验证离线网页的能力识别与权限管理。
- 修复全屏白屏页面中更多菜单无法显示复制链接的问题。

## English

- Web apps can check environment, declared capabilities and authorization status.
- Improve capability identification and permissions for verified offline pages.
- Fix the copy-link action in the immersive More menu when the page is blank.
