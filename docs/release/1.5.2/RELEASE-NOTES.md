# Drel 1.5.2 Release Notes

Draft for TestFlight; pending physical microphone acceptance and App Review decisions.

## 简体中文

- 已签名的网页应用可以在用户授权后使用实时音量，控制互动内容。
- 提供声音跳跃和吹蒲公英 H5 测试示例；麦克风授权可在权限中心撤销。

## English

- Signed web apps can use live sound level for interactive experiences after user consent.
- Voice jump and dandelion H5 demos are available for testing; revoke microphone access in the permission center.
