# Drel 1.0.1 What's New

The 1.0.1 line was the TestFlight patch round that closed out the 1.0 App
Store submission (2026-09-11, build 65). It shipped no new capability.

## zh-Hans

```text
Drel 1.0.1 更新

• 稳定性修复：修复若干界面显示与推送展示问题
• 界面整理：收件箱、设置与应用中心的显示更稳定
```

## en-US

```text
What's new in Drel 1.0.1

• Stability fixes: corrected several display and push presentation issues
• Interface cleanup: the Inbox, Settings and the app center render more consistently
```
