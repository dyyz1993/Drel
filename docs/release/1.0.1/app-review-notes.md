# Drel 1.0.1 App Review Notes

Status: historical record. The 1.0 submission and its Guideline 2.1 response
are closed; this document preserves the review narrative as submitted.

## Summary

Drel is a developer push-notification utility and a focused web container.
Version 1.0.1 is a patch release of the 1.0 line. It introduces no new
capability and no new privacy usage description.

## Reviewer walkthrough

No account, login, purchase, subscription, or credentials are required.

1. Launch Drel and allow notifications if you want to test push delivery.
2. Use the built-in test-send controls to deliver a harmless test message.
3. Open the Inbox and confirm the message renders with its title and body.
4. Open Settings and confirm the push channel, storage management and
   appearance sections.

## Permissions and privacy

The notification permission is optional; denying it leaves the app usable.
Drel collects no analytics, requires no account, and shows no advertising.
