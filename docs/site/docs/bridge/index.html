Bridge API Reference

Drel can invoke native actions on your page's behalf — but only what an Ed25519-signed manifest explicitly declares and the user allows. This is not a general, unrestricted JavaScript-to-native bridge.

The authorization chain

Every controlled action passes six security checks before any native handler runs. A failure at any step fails closed, never crashes the app.

# Check Fails when
1App identityThe page was opened as an ordinary URL, not from a registered application.
2Exact declarationThe signed manifest's capabilities_v2 does not declare that action for that origin.
3Origin matchThe page origin is not in the declared origin list, compared exactly (scheme://host:port).
4Foreground gestureNo recent user touch event consumed the call (blocks background automation).
5Grant ledgerNo stored grant covers this gateway, app, origin, and action tuple.
6Native promptThe user cancels or rejects the native permission sheet.
Declaration is not consent. A manifest entry is an allowlist. It never substitutes for the user's decision, and it never widens what a page can reach.

Submitting an approval to a third-party service

An approval card can also hand its decision to a service you run yourself, instead of the Drel gateway. The phone receives a short-lived ticket and a submit URL in the notification, and posts the result back as structured JSON. The third-party service keeps the policy, the replay protection and the audit trail; the phone only carries the user's answer.

Declared actions (Manifest v2)

Versioned host contract: Drel 1.5.0 exposes the seven original actions and, starting with build 130, sensors. Drel 1.5.2 build 138 adds audioLevel in TestFlight; check App Store availability before relying on it. Every action requires a signed declaration and exact origin. audioLevelalwaysDrel 1.5.2 build 138 TestFlight: normalized foreground microphone level, consent required; raw audio is not exposed.
addToHomeScreenappSessionAdds the registered app shortcut to the Drel home screen.

Manifest declaration format

Declared in the parent manifest under capabilities_v2:

{
  "action": "clipboard",
  "origins": ["https://app.example.com"],
  "purposeId": "paste-order-number",
  "purpose": "把订单号粘贴到表单里",
  "scope": "always"
}

Not available

Camera scanning, photo library, Bluetooth, raw microphone audio, speech recognition, contacts, file import/export, and generic device control are not exposed as managed actions in the Drel Store host. Motion sensors and foreground audio level are separate scoped actions as listed above; audioLevel is not raw audio or speech recognition.

Calling an action

const bridgeAvailable = typeof window.BarkBridge?.callNative === 'function';

if (bridgeAvailable) {
  try {
    const result = await window.BarkBridge.callNative('clipboard', { action: 'read' });
    if (result?.success) {
      input.value = result.data;
    }
  } catch (error) {
    // Fall back to manual paste or browser fallback
  }
}

Always write the fallback. A page that breaks when the bridge is missing is not a valid Drel app — it must also work in a plain browser.

Runtime detection

const runtime = window.DrelRuntime;
const isInstalledOffline = runtime?.isOfflinePackage === true;
const bridgeVersion = Number(runtime?.bridgeVersion ?? 0);

Feature-detect; do not sniff the user agent string. The app version is not an authorization level.
