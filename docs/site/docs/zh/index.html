从一条推送地址开始

Drel 提供推送接口，也为已签名的可信网页提供受控原生能力。这是两个独立接口：发送推送不需要 Bridge，推送本身也不会授予网页权限。

1. 获取地址与发送通知

在 Drel 首页复制“你的推送地址”，形如 https://api.drel.app/<YOUR_DEVICE_KEY>。地址就是向你的设备发送通知的凭证，不要提交到仓库、截图或公开日志。

把下列占位地址换成自己的地址；执行命令会实际发送一条通知：

DREL_PUSH_URL='https://api.drel.app/YOUR_DEVICE_KEY'
curl --get "$DREL_PUSH_URL" \
  --data-urlencode 'title=Build complete' \
  --data-urlencode 'body=Your build is ready'

也可以使用 JSON；命令中的 YOUR_DEVICE_KEY 是占位符，先在私有环境中替换：

curl https://api.drel.app/push \
  -H 'Content-Type: application/json' \
  -d '{"deviceKey":"YOUR_DEVICE_KEY","title":"Build complete","body":"Your build is ready"}'

仅打开不带消息参数的个人地址可查看发现信息；追加标题、正文或填写推送字段会触发发送。请求成功不等于用户已看到通知。详见 Push API。

2. 版本与能力

推送协议与 iOS App 版本分别演进。下面是已核对的版本边界；安装包、签名清单和用户授权共同决定实际可用能力。

能力最低 Drel 版本条件
Bark 兼容推送、打开 HTTPS 页面1.4.x个人地址；无需网页 Bridge
haptic、vibrate、share、fullscreen、clipboard、getLocation、addToHomeScreen1.5.0签名清单声明和可信来源；132 起受控动作均需前台用户操作
sensors 加速度与陀螺仪1.5.0（130 起）130 为声明式；131 起需用户同意且可撤销；132 起要求前台点击
audioLevel 实时音量1.5.2（TestFlight 138）签名声明、用户点击、Drel 与 iOS 麦克风授权；正式商店可用性以商店版本为准

audioLevel 返回 0–1 的音量值，最高 30 次/秒，不提供原始音频或录音文件；它不是实时语音识别或翻译。Bridge 完整参考 · Action Demo。

读取版本与运行环境

Drel 网页可读取 window.DrelRuntime；普通浏览器可能没有此对象。UA 也包含 Drel 版本、构建号和协议版本，但不表示某个能力已经授权。

const r = window.DrelRuntime;
console.log({ appVersion: r?.appVersion, buildNumber: r?.buildNumber,
  bridgeVersion: r?.bridgeVersion, containerVersion: r?.containerVersion,
  offlinePackageVersion: r?.offlinePackageVersion,
  isOfflinePackage: r?.isOfflinePackage, screen: r?.screen, viewport: r?.viewport });

版本与构建号是字符串；屏幕与视口会随运行环境变化。服务端可从 User-Agent 识别 Drel，网页优先使用结构化字段。不要将 UA 或版本号当成授权凭证。

能力与授权查询（1.5.3 测试版）

计划随 1.5.3（139）TestFlight 提供：以下 getCapabilities 接口的正式商店可用性以实际发布为准。旧版（包括 1.5.2 Build 138）请处理不支持的返回，不要假设所有用户已经升级。

async function readCapabilities() {
  const bridge = window.BarkBridge;
  if (typeof bridge?.callNative !== 'function') return null;
  try {
    const result = await bridge.callNative('getCapabilities', {});
    return result?.success === true ? result.data : null;
  } catch { return null; } // 旧版容器或普通浏览器
}

返回 schemaVersion: "1" 和按动作名索引的 actions。每项的 supported 表示宿主允许该动作；declared 表示当前可信页面匹配签名声明；appPermission 与 systemPermission 分别反映 Drel 和 iOS 的授权状态。requiresUserGesture 表示实际操作仍需用户点击。

// 示例（字段值会随页面、授权和宿主而变化）
{
  "schemaVersion": "1",
  "actions": {
    "audioLevel": {
      "supported": true, "declared": true,
      "appPermission": "notDetermined", "systemPermission": "notDetermined",
      "requiresUserGesture": true
    }
  }
}

appPermission 可能为 granted、notDetermined、notRequired 或 unavailable；notDetermined 也包括没有持久授权的情况，不能据此判断用户从未拒绝。systemPermission 可能为 granted、denied、restricted、notDetermined、notRequired 或 unavailable。只有持久授权才会包含 grantScope。

查询不弹窗、不申请授权，结果只是当前快照，并不保证设备硬件可用或后续调用成功。用户在设置里更改授权后应重新查询；需要授权时应由用户点击实际功能并等待成功回调。一次性授权不会被记作长期授权。已验证离线入口会映射到启动时的可信地址；其他离线页面须匹配已安装包的摘要验证资源清单及文件内容。旧离线包可能需要重新下载才能识别其他页面。

3. 在网页中调用 Bridge

在受信任应用的签名清单中逐项声明 capabilities_v2、用途和准确 origin。声明不等于授权；敏感动作只能在前台由用户操作触发，并等待成功回调后继续。

button.addEventListener('click', async () => {
  if (typeof window.BarkBridge?.callNative !== 'function') return;
  try {
    const result = await window.BarkBridge.callNative('clipboard', { action: 'read' });
    if (result?.success !== true) return; // 用户取消或授权失败
    // 只有成功后才继续处理 result
  } catch (error) {
    // 展示失败原因或提供普通浏览器替代方式
  }
});

位置声明使用 getLocation；旧清单中的 location 是兼容别名，JavaScript 动作名仍为 getLocation。普通网页不要假设拥有受控原生权限。

5. 调试与安全

  • 普通浏览器先做标准 Web 功能，Bridge 缺失、拒绝或取消时提供降级。
  • 传感器和音量订阅不在后台持续采集；离开、撤销或停止时关闭。
  • 不要把密钥、设备推送地址、用户位置或录音写进公开示例、Schema、截图或日志。
