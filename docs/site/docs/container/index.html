Web Container Behavior

Drel opens an exact HTTPS destination in a focused iOS native web container. It gives a page environment awareness, not unprompted device authority.

Navigation and presentation

InputBehaviorBoundary
HTTPS urlOpened after the user taps a notification or a message.Use a publicly trusted HTTPS certificate. Plain HTTP is rejected in Store builds.
mode=normalStandard Drel web container.Normal is the safe default for unknown or absent mode.
mode=immersiveFullscreen Drel container with an expandable edge return control.The return/refresh control remains available; a webpage cannot suppress it.
mode=modalCompact modal presentation.Presentation is not a permission grant.

Drel preserves the destination URL and its query string. It does not append login credentials, device tokens or a trusted “push source” marker. Do not use URL parameters or referrer values as authorization proof.

Runtime environment

At document start, Drel exposes a read-only window.DrelRuntime object. Pages must feature-detect it and continue to work as ordinary web pages when it is missing.

window.DrelRuntime = {
  runtime: "web" | "offline-package",
  isOfflinePackage: true | false,
  presentation: "normal" | "immersive" | "modal",
  screen: { width, height, dpr },
  viewport: { width, height, scale },
  containerVersion: 1,
  offlinePackageVersion: 1,
  bridgeVersion: 0
}

The user agent also includes a versioned Drel product token. screen is a hardware baseline, while viewport, CSS safe-area variables and window.visualViewport reflect the current layout.

Web compatibility and storage

Store container isolation. Remote web pages receive no unprompted native command surface. Standard browser APIs remain subject to iOS, WKWebView and the user’s permission settings, so feature-detect before depending on an API.
  • Origin storage such as cookies, IndexedDB and localStorage is available as normal web storage, but is not a permanent backup guarantee. Users, iOS or an app uninstall can clear it.
  • Do not rely on popups, arbitrary downloads, background execution or camera access without testing the exact iOS release and providing a normal web fallback.
  • Resetting a Drel push address protects the notification capability. It does not erase a website session or any web-origin data.

Push context and lifecycle

A notification can select a destination and presentation; it cannot silently approve a request, install an app, modify an offline package, or execute a sensitive native action. The page receives its own URL and normal browser lifecycle events.
