Push API Reference

Use the personal push address generated by Drel on your phone as your bearer capability. Send plain text, open exact HTTPS destinations, or route into registered web applications.

Moving from Bark

Drel provides drop-in compatibility for Bark client requests. Read the Bark compatibility and migration guide or the 中文迁移指南 before adapting existing CI or automation scripts.

Endpoints

Form Endpoint When to use it
Bark-compatible pathGET /<key>/<title>/<body>Simple shell scripts and curl with scalar query parameters.
Bark-compatible POSTPOST /<key>Form or JSON request bodies while keeping the device key in the path.
Structured JSONPOST /pushUse for structured parameters, including params, rich content, and app routes.
 
curl "https://api.drel.app/YOUR_KEY/Build%20complete/Open%20the%20report" -G \
  --data-urlencode "url=https://tools.example/release/42" \
  --data-urlencode "mode=immersive"
curl https://api.drel.app/push -H 'content-type: application/json' -d '{
  "deviceKey": "YOUR_KEY",
  "title": "Build complete",
  "body": "Open the report",
  "url": "https://tools.example/release/42",
  "mode": "immersive",
  "params": { "build": "42" }
}'

Stable fields

Field Purpose Notes
title, body, subtitleNotification textRequired title/body for normal direct messages. Keep all content non-sensitive.
urlHTTPS destinationOpens in Drel after an explicit notification tap. Must be a trusted HTTPS URL.
mode / displayPresentationnormal, modal, and immersive are supported. Aliases full and fullscreen map to immersive.
appId, route, paramsRegistered web app launchUse JSON POST when nested params are needed. Route must match the signed manifest.
group / threadId, badge, soundOrganization and soundiOS notification settings and system delivery policies remain authoritative.
icon, imageIn-app image metadataAn icon never replaces Drel’s iOS App Icon. Images must use HTTPS.
markdown, contentTypeRich inbox contentUse the JSON endpoint for explicit typed message contracts.
copy, autoCopy, isArchiveInbox behaviorsUse only where clear to the user; do not use a push to trigger sensitive changes.

Fields outside this table may exist for internal or experimental compatibility. Do not build production integrations around undocumented fields.

Responses, retries, and delivery

A successful direct request returns a JSON response: {"code":200,"attempted":1,"accepted":1,"expired":0,"message":"…"}. Errors return {"error":{"message":"…"}}.

Accepted is not displayed. A 200 response means the Drel relay accepted the request and forwarded it to Apple APNs. A phone may be offline, disabled for notifications, or subject to iOS Focus mode.

Key rotation and privacy

Reset your push address from Drel Settings if it ever leaks. The official delivery service processes requests to deliver them and is not an end-to-end secret channel. See Privacy Policy.
