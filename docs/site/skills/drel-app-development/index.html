Drel app development

Give an agent the current contract for Drel web apps, strong offline packages and push routes—without accidentally assuming a native Bridge.

1.5

Compatible with Drel 1.5.x

Standard Web App Manifest, signed application identity, opt-in offline packages, push route validation and declared native actions.

0

Bridge version 0

The current Store container exposes no native JavaScript Bridge. The skill stops agents from inventing camera, file, clipboard or permission APIs.

✓

Release-aware

Includes the physical-device cases for package updates, airplane mode, rollback, deletion and asynchronous network data.

Install

Add it to your agent.

The command below uses the legacy public WebBridgeKit repository for skill distribution. Drel and WebBridgeKit-Framework development have moved to separate private repositories; this command does not install their current source. Use the versioned ZIP for a manual import.

  terminal
# Install only this Drel skill
npx skills add dyyz1993/WebBridgeKit --skill drel-app-development

Scope

Offline is an installation contract, not a cache promise.

Static files are verified and installed locally only after a user action. APIs and live data continue to use the network, with an explicit offline fallback.
