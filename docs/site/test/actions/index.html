原生操作演示

这个页面验证 Drel 的 Manifest v2 原生操作运行时。触感、震动、分享和沉浸全屏四项能力由网关签名的父清单逐项声明，页面只负责在用户点按后调用。

体验步骤

  1. 在 Drel 中打开这个应用（或先把它注册为可信应用）。
  2. 点按「触感反馈」「短震动」，感受一次原生反馈。
  3. 点按「系统分享」，会拉起 iOS 系统分享面板，可以直接取消。
  4. 点按「切换沉浸全屏」，观察导航栏隐藏与屏幕边缘的返回控件。
  5. 剪贴板与定位需要一次性授权，可在 Drel 的权限中心撤销。

测试材料

  • 在线预览
  • Web App Manifest
  • 网关父清单（待签名）

这是一个纯网络应用：它不发布强离线包，所以没有 package.json。声明式操作不构成长期授权，每次分享仍由系统面板决定去向。
