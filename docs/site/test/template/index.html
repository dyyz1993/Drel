数据模板应用

这是一个可复用的应用骨架：页面结构、样式和图标已就位，运行时数据从模板变量注入。它同时发布强离线包，用来演示「同一份源码如何既联网取数又能离线启动」。

体验步骤

  1. 在 Drel 中打开这个应用，观察模板变量渲染出的内容。
  2. 在应用详情里安装离线包，让资源在本地按 SHA-256 校验后保存。
  3. 断开网络后重新启动，页面仍能打开。

测试材料

  • 在线预览
  • Web App Manifest
  • Drel 资源清单
  • 网关父清单（待签名）
  • 诊断 ZIP

诊断 ZIP 仅供人工检查，运行时不会执行它。要复用这个骨架，请复制构建脚本并替换脚本头部的四值：源码目录、公网根地址、应用 ID 和版本号。
