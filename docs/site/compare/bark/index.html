Coming from Bark?

If you are looking for a Bark alternative for iPhone push notifications, Drel supports familiar HTTP push requests and opens the linked HTTPS destination inside its web container after you tap a notification. Start with one script, then verify the options your workflow depends on.

中文

What the two apps have in common

Bark is an open-source iOS push notification app. Its documented API includes GET and POST requests with notification text, URL, grouping and sound options. Drel accepts basic Bark-style requests, making shell scripts and CI notifications a useful starting point.

Drel is an independent product with no affiliation or endorsement from Bark. This guide describes Drel's documented interface, not full feature parity or compatibility with every Bark integration.

Choose by your workflow

  • For custom iPhone alerts, review Bark's official documentation alongside the Drel Push API.
  • For a notification that opens a report or dashboard inside Drel, include an HTTPS url. Read the web container guide.
  • For installed offline web content, read Drel's offline package contract. Live API data may still require a network connection.

Migrate a basic Bark-style request

  1. Install Drel, enable notifications and copy your Drel push address.
  2. Replace the server and key in a test script with that address. Bark keys and device registrations do not transfer.
  3. Keep title and body URL-encoded. Verify delivery and the page opened after tapping.
curl 'https://api.drel.app/YOUR_DREL_KEY/Build%20complete/Open%20report' -G \
  --data-urlencode 'url=https://tools.example/release/42'

Your push address is a sending secret. Keep real keys out of public repositories and screenshots. This example uses placeholders.

Check before switching your automation

  • Validate optional parameters against the Drel field reference. Do not assume Bark encryption formats, critical alerts, volume controls or call-style notifications behave identically.
  • Inspect the response body and HTTP status. Accepted does not prove that the phone displayed a notification.
  • Test locked-screen delivery on your iPhone. Permissions, Focus and connectivity affect the result.
  • For self-hosting, read the Drel service guide; credentials and pairing require their own setup.

Can I use my existing Bark key?

No. Use the address generated by Drel. This migration reuses a basic request format, not Bark credentials, history or device registrations.

Do I have to uninstall Bark?

No. Try a separate Drel notification before changing production scripts.

Where can I download Drel?

Download Drel on the App Store, then follow the developer documentation.
