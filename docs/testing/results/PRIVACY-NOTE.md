# Physical-device evidence retained privately

Screenshots captured on the physical iPhone used for release validation
(`drel-1.4.1-89-iphone-validation/*.jpg`, `iphone-1xx-*` series across
`drel-1-5-0-113-cleanup`, `drel-1-5-0-118-verification`,
`drel-1-5-0-121-navigation`, `drel-gesture-gate`, `drel-gyro-sensors`)
are excluded from this public repository because they show the
personal device home screen, real share targets, and live push
endpoint fragments.

The complete evidence sets are retained in the maintainer's private
records. Markdown documents in these directories may reference the
removed files; those links resolve only in the private copy.

Simulator captures and in-app screenshots with fixture values remain
in the repository.
